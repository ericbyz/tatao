# 界面规范

界面以“工程工具”而不是“AI 产品”为视觉基调。主视图优先使用表格、列表和上下文面板，减少卡片堆叠。

## 视觉语言

- 背景：主区域纯白；侧栏使用冷灰 `#f5f7fa`。
- 文字：主文字 `#142033`，次要文字 `#607089`。
- 强调色：操作蓝 `#1769e0`；成功绿与警告橙只表达状态。
- 边界：1px 中性灰线；阴影仅用于弹窗。
- 圆角：控件 5px，弹窗 8px，避免大面积胶囊与超大圆角。
- 字体：系统中文无衬线；标题 24px，正文 14px，控件 13px。

## 页面骨架

```text
┌──────────┬─────────────────────────────┬──────────────┐
│ 左侧导航 │ 标题 / 工具栏               │ 上下文详情   │
│          ├─────────────────────────────┤              │
│          │ 表格 / 列表 / 表单          │ 动态与操作   │
└──────────┴─────────────────────────────┴──────────────┘
```
